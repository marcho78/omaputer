# omarchy_fx

The effects behind the Launcher's Omarchy screensaver (`src/omarchy_screensaver.cpp`): Omarchy's logo animated with six effects ported from Omarchy's `ttfx`.

This is a copy of `lib/omarchy_fx` from the Cardputer screensaver project (commit 8d3627c). Its unit tests, frame-by-frame comparison with `ttfx`, and GIF previews live in that project. Change the effects there, then copy them here again.
